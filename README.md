## 任务概述
开发一个单页面网页，实现"点击链接 → 弹出省份选择框 → 江苏省显示13个地级市二级选项 → 选择后展示对应地区图片"的完整流程。图片文件命名规则为 `xx.jpg`。

## 功能需求
### 1. 入口链接
- 页面中央显示一个可点击的链接或按钮，文案为"选择目的地"或"点击查看"。
- 点击后弹出一个模态框（Modal）或下拉选择面板。
### 2. 省份选择（一级选项）
- 选择框中列出中国全部 **31 个省级行政区**（22个省、5个自治区、4个直辖市、不包括港澳2个特别行政区及台湾省）。
- 使用 `<select>` 或自定义下拉组件实现。
### 3. 地级市选择（二级选项，仅江苏省）
- 当用户选择 **"江苏省"** 时，动态显示第二个下拉框，列出江苏省 **13 个地级市**：
南京、无锡、徐州、常州、苏州、南通、连云港、淮安、盐城、扬州、镇江、泰州、宿迁
- 选择其他省份时，二级选项隐藏或不显示。
### 4. 图片展示
- 用户完成选择后，关闭选择框，在页面中展示对应地区的图片。
- 图片文件命名规则：
    - 普通省份/直辖市/自治区/特区：直接用名称，如 `北京.jpg`、`西藏.jpg`、`香港.jpg`
    - 江苏省地级市：用城市名，如 `南京.jpg`、`苏州.jpg`
    - 其他省份若未来扩展二级选项，同理用下级名称
- 图片存放于项目根目录下的 `images/` 文件夹中。
- 若图片不存在，显示友好的提示文字，如"暂无该地区图片"。
