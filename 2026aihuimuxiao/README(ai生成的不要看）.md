# 2026 爱回母校 · 地区 QQ 群二维码页

纯静态单页：点击「选择省市」→ 选省份 → 江苏省再选 13 个地级市 → 展示对应地区 QQ 群二维码。
无后端、无构建步骤，任意静态服务器都能直接跑。

## 目录结构

```
region-qr/
├── index.html          页面结构
├── assets/
│   ├── style.css       样式（深色、响应式、含手机底部弹层）
│   └── app.js          省份/城市数据 + 交互逻辑
├── images/             43 张二维码（30 个省级地区 + 江苏 13 市）
└── README.md
```

## 本地 / 局域网预览

```bash
node tools/server.js 8080      # 在仓库根目录执行
```

- 本机：http://localhost:8080
- 同一 Wi‑Fi 的其他设备：http://<电脑局域网 IP>:8080

也可以直接把 `region-qr` 整个目录丢给任何静态托管（Nginx、Apache、GitHub Pages、Netlify、Vercel…），
只要保证 `index.html`、`assets/`、`images/` 保持相对位置即可。

## 公网链接（临时）

当前机器上运行着 Cloudflare 快速隧道，公网地址形如：

```
https://<随机名>.trycloudflare.com
```

- 优点：免注册、立刻能发给别人、手机流量也能打开。
- 限制：进程或电脑一停就失效，重启后地址会变；不适合长期对外。
- 重新启动：

```bash
node tools/server.js 8080
tools/cloudflared.exe tunnel --url http://127.0.0.1:8080 --no-autoupdate
```

终端里会打印新的 `https://xxx.trycloudflare.com`。

**需要固定链接时**，把 `region-qr` 目录部署到静态托管（推荐 Netlify Drop：拖拽文件夹即可，
或 GitHub Pages / Vercel）。绑定自己的域名后，链接就永久稳定了。

## 交互说明

- 省份下拉包含 31 个省级行政区（22 省、5 自治区、4 直辖市）。
  按需求未列入香港、澳门、台湾；如以后需要，在 `assets/app.js` 的 `REGIONS` 末尾补三项并放入图片即可。
- 只有选择「江苏省」时才出现第二个下拉框，13 个地级市：南京、无锡、徐州、常州、苏州、南通、
  连云港、淮安、盐城、扬州、镇江、泰州、宿迁。
- 选择后关闭弹窗，在页面中展示二维码；加载时显示骨架屏 + “正在加载二维码…”。
- 图片找不到时显示「暂无该地区图片」并提供「重新选择」。
- 直接分享某个地区：在链接后加 `?r=南京` 或 `?r=北京`，打开即显示该地区二维码。

## 图片规则

- 文件名即地区简称：`北京.jpeg`、`南京.jpeg`、`内蒙古.jpeg`、`广西.jpeg`、`宁夏.jpeg`、`新疆.jpeg`、`西藏.jpeg`。
- 代码按 `jpeg → jpg → png → webp` 顺序自动探测，所以 `xx.jpg`、`xx.jpeg`、`xx.png` 都能直接用。
  现有图片多为 `.jpeg`，福建、陕西为 `.png`。
- 新增地区：把图片放进 `images/`，文件名用简称；若该省未来要细分城市，在 `REGIONS` 里给对应省份
  加 `cities: [...]`，并在 `images/` 放城市图即可，无需改其他代码。
